🔐 TruffleHog AutoScan

Automatisiertes Secret-Scanning für GitHub-Repositories – täglich um 02:00 UTC via GitHub Actions. 🕵️‍♂️

Automated secret scanning for GitHub repositories – daily at 02:00 UTC via GitHub Actions. 🕵️‍♂️

✨ Was macht dieses Setup?

  • Scannt bei jedem Push auf main/master auf Secrets
  • Führt täglich um 02:00 Uhr UTC einen vollständigen Scan aus
  • Nutzt die offizielle TruffleHog GitHub Action aus dem Marketplace
  • Meldet nur verifizierte Secrets (--only-verified) – weniger False Positives

✨ What does this setup do?

  • Scans on every push to main/master for secrets
  • Runs a full scan daily at 02:00 UTC
  • Uses the official TruffleHog GitHub Action from the Marketplace
  • Only reports verified secrets (--only-verified) – fewer false positives

⚙️ GitHub Actions WorkflowGitHub Actions Workflow

Datei: .github/workflows/trufflehog.yml

File: .github/workflows/trufflehog.yml

name: TruffleHog Secret Scan

on:
  schedule:
    - cron: '0 2 * * *'   # daily at 02:00 UTC
  push:
    branches: [ main, master ]

jobs:
  trufflehog-scan:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - name: Run TruffleHog OSS
        uses: trufflesecurity/trufflehog@main
        with:
          extra_args: --only-verified
